Calculadora de láminas de riego

Lámina neta, lámina de riego y frecuencia a partir del suelo, la raíz y la evapotranspiración del cultivo

Datos del suelo y del cultivo

Las láminas se calculan sobre el área neta (superficie realmente regada). CC y PMP se ingresan como humedad gravimétrica (%), tal como las reporta el laboratorio.

Ingrese los datos para calcular las láminas y la frecuencia de riego.
Fórmulas utilizadas
Lr (L/m²) = (CC − PMP) / 100 · Profundidad de raíz (mm) · Da Lr (m³) = Lr (L/m²) · Área neta / 1000 Ln (L/m²) = Lr (L/m²) · Agotamiento / 100 Ln (m³) = Ln (L/m²) · Área neta / 1000 Frecuencia (días) = Ln (m³) / ETr (m³/día)

La frecuencia se redondea hacia abajo para no pasar el agotamiento permitido. Es un cálculo preliminar: no incluye eficiencia de aplicación, lluvia, aporte capilar ni variación del Kc durante el ciclo.

Herramienta elaborada por Sergio Solano Romero, Ingeniero Agrícola. El cálculo es preliminar y no sustituye el diseño técnico, los estudios de suelo ni la revisión de un profesional.
